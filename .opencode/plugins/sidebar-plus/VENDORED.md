# Vendored copy

This folder is a copy of [opencode-sidebar-plus](https://github.com/dskanakoglou/opencode-sidebar-plus)
v0.2.0 (commit 50ada63), so it loads automatically when OpenCode opens the
workshop folder. OpenCode loads every plugin folder in `.opencode/plugins/`;
no entry in `opencode.json` is needed.

Do not edit it here. Change the upstream repository and copy it again.
To switch it off for yourself, type `/sidebar` and choose **Minimal**, or delete
this folder.
