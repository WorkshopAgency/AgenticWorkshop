# Plugins

OpenCode loads every plugin folder it finds here when it starts. The
workshop uses two, which you clone here in
[Exercise 0](../../exercises/00-plugins/README.md):

| Folder | What it adds |
|---|---|
| `opencode-sidebar-plus/` | A sidebar with agent activity, tool calls, tokens and cost |
| `opencode-notebook/` | A notebook panel with a shared Python kernel, and the `notebook_run` and `notebook_read` tools |

Only this README is in Git: the plugins are someone else's code, pinned to a
version you choose, so you clone them yourself rather than receive them with
the workshop.

- **Add one:** clone it into its own folder here, then restart OpenCode.
- **Update one:** delete its folder and clone the newer version.
- **Remove one:** delete its folder and restart OpenCode.

A plugin runs with your access to this computer. Read what it does before
you put it here.
